# 云台 PID 重构设计

## 目标

将云台两轴收敛为唯一的 INS 角度-角速度串级 PID 控制链。遥控器负责选择
手动或自瞄模式；上位机仅在自瞄模式下提供绝对 yaw/pitch 目标。保留拨弹轮和
摩擦轮控制，删除云台任务中与底盘跟随、巡航和小陀螺有关的控制代码。

## 模式与输入优先级

1. 左、右拨杆均为上位时：`AIMBOT_ON`。仅当视觉目标有效时，yaw/pitch 使用
   上位机的绝对角度目标；无效帧保持最后一个合法目标。
2. 左拨杆为下位时：急停。云台和发射机构 CAN 输出均为零。
3. 其他有效拨杆组合：手动模式。摇杆和鼠标增量累加为 INS 绝对角度目标。
4. 手动和自瞄切换时，均以当前 INS 姿态重置手动锚点，避免目标突跳。

## 模块边界

- `application/aimbot_gimbal.[ch]`：云台两轴的模式选择、目标生成、反馈更新、
  串级 PID 计算及输出电流；接口命名与 `gimbal_task.c` 保持一致。
- `application/gimbal_task.[ch]`：仅保留任务调度、拨弹轮/摩擦轮 PID、射击模式
  与激光控制；删除底盘控制依赖和所有底盘命令。
- `application/aimbot_task.[ch]`：只接收和保存上位机目标，不直接改变云台模式。

## 控制链

`目标角度 -> 角度 PID -> 目标角速度 -> 角速度 PID -> 电机电流`

两轴均使用 INS 姿态做角度反馈、IMU 角速度做速度反馈。pitch 目标在机械角度
范围内限幅；yaw 目标按 `[-PI, PI]` 回环。视觉数据仅在有限值且位于合理角度
范围内时更新保持目标。

## 安全与验证

- 急停始终优先于自瞄和手动。
- 自瞄目标在视觉数据丢失、NaN 或超范围时不会覆盖最后合法目标。
- PID 输出沿用当前限幅参数；不在本次修改中改变硬件参数。
- 使用 Keil 工程进行完整编译，并检查项目文件是否包含新增/修改的源文件。
